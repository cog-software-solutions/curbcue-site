# CurbCue policy pages

The privacy policy, terms of use and support page that the app stores link to. Plain static HTML served by GitHub Pages; no build step.

- `privacy/`, `terms/`, `support/`: one page each. Edit the HTML directly.
- `assets/site.css`: colours and fonts from the `curbcue-brand` skill tokens, light and dark.
- `assets/fonts/`: Atkinson Hyperlegible and Bricolage Grotesque, under the SIL Open Font License (the OFL files sit beside them).

The first version came from CurbCue's drafts in `garbage-schedule/docs/release/` (privacy-policy, terms-of-use and support-page drafts). This repo is now the source for the live text. If the app changes in a way a page describes, update the page and its effective date in the same change.

Use only COG Software Solutions and info@cogsoftwaresolutions.com on these pages: no personal name, home address or phone number.
